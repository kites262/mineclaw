id: server-guide
name: 服务器向导
description: 回答服务器规则或玩法问题前使用的 Workspace 导航说明
triggers:
  - 玩家询问规则、玩法或服务器文档
  - 玩家询问服务器是否支持某项能力
---

1. 先使用 `grep` 搜索玩家问题中的关键名词；需要浏览目录时使用 `list`。
2. 对候选文件使用 `read` 获取完整原文，包括 Skill 顶部的 YAML 元数据。
3. 只根据读到的 Workspace 内容说明服务器规则、玩法或能力；不要从常见插件、命令名称或其他服务器经验推断。
4. 若没有相关资料，明确说当前 Workspace 未提供答案或能力说明，不要编造命令和替代能力。
